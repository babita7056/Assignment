## Seed data
After any DB reset or fresh deploy, call `POST /api/posts/refresh` once. The scrape is async (returns immediately), completes in ~30–60s with OpenAI batch summaries.

## Scraper
- Reddit: fetches /r/passport and /r/travel via public JSON API (no auth), 5s timeout, fails gracefully
- Mock: 60 realistic posts spread across 6 platforms (Twitter/X, LinkedIn, Facebook, Instagram, YouTube, TikTok)
- Scrape clears all posts and re-inserts — no incremental update

## NLP pipeline (lib: `artifacts/api-server/src/lib/nlp.ts`)
- Categorize: keyword scoring against 10 categories
- Sentiment: positive/negative/neutral from word lexicon
- Gibberish filter: word length, char ratio, unique chars, repeated pattern
- Summary: OpenAI gpt-4o-mini, 5 concurrent, ~20–30 words each
- Translate: OpenAI gpt-4o-mini, on-demand, cached in DB per post/language
- Cluster: hash of (category + top 3 keywords)

## API routes
- `GET /api/posts` — list with filters (platform, category, sentiment, language, region, search, sortBy, sortOrder, clustered, page, limit)
- `POST /api/posts/refresh` — async scrape trigger
- `GET /api/posts/export?format=csv|pdf` — exports filtered posts
- `POST /api/posts/:id/translate` — translate single post
- `GET /api/stats`, `/api/stats/platforms`, `/api/stats/categories`, `/api/stats/sentiment`, `/api/stats/timeline`

## Frontend (artifacts/dashboard)
- Dark "mission control" theme, amber (`--primary: 37 91% 55%`) accent, JetBrains Mono + Inter
- `Dashboard.tsx`: StatCards + PostFeed (left, 2/3) + TimelineChart + SentimentChart (right, 1/3)
- `Analytics.tsx`: 4 charts (platform posts, platform engagement, category, sentiment) + full-width timeline
- All data from TanStack Query hooks generated by Orval from the OpenAPI spec

**Why contract-first:** Zod validators and React Query hooks are auto-generated from the spec; any drift between client and server is caught at codegen time.

**How to apply:** If adding a new endpoint, write it in `lib/api-spec/` first, run codegen, then implement the route and consume the hook — never hand-write the client.
